Language reference · F0

Science

A compiled language for scientific computing and machine learning. Native binaries through LLVM, memory managed by ownership and borrows verified at compile time with no garbage collector and no lifetime annotations. Blocks are indentation; keywords are English words where no symbol is universal, and symbols where one is.

What this page is, and what the compiler is

This page describes syntax revision 2, which is the language as designed. Most of it is what sciencec lexes, parses and resolves today. The error model of the Errors section is the exception: pairs like -> (Config, Error?), the nullable type T?, the presence test ? and the literal null are decided and half implemented. The syntax landed: a compiler you install today lexes, parses and resolves every one of them, and no longer accepts the Result / try forms they replace. What has not landed is what they mean — the narrowing that makes if err?: tell the compiler that err is not null, and the check that refuses a returned error nobody tested. Both need a type checker, and there is not one yet. So these blocks compile and are not yet verified, which is a different and smaller gap than the one this paragraph described until the syntax shipped.

Getting started#

A file is a module and needs no scaffolding beyond a main. Save this as hello.science. 

type Doc:
    title: String
    body: String

def main():
    let doc be Doc(title: "Regions", body: "A region is a set of program points.")
    print(doc.title)

    for i in 0..3:
        print(i)
$ sciencec check hello.science
$ echo $?
0

check is silent when a file is clean and exits 0. Anything it finds goes to stderr with a code, a span and, where a fix exists, the exact replacement text. Warnings alone do not fail the run.

Bindings and literals#

let … be introduces a name. be on its own assigns to one that already exists. Bindings are immutable unless declared mutable. 

let title be "Regions"
let mutable count be 0
let width: Int be 768              # the annotation is optional

count be count + 1                 # assignment
self.text be ""

const WIDTH be 768                 # compile-time constant
type Embedding is Array of F32     # type alias

Literals

let decimal be 1_000_000
let hex be 0xdead_beef
let octal be 0o777
let binary be 0b1010
let sized be 42i32

let pi be 3.14
let tiny be 1e-9
let single be 2.5f32

let greeting be "hola"
let escaped be "a\tb\nc \u{1F600}"
let letter be 'a'
let flag be true
let nothing be ()

let missing: Error? be null        # absence, and the only spelling for it

null is a literal like true and false: its spelling is fixed, so a program may not bind the name. It inhabits a nullable type T? and nothing else — () above is the empty tuple, which is a value, not an absence. changing

Escapes in full: \n \t \r \\ \" \' \0 \u{…}. Numeric types are I8 … I64, U8 … U64, F16, BF16, F32, F64, with Int and Float as the defaults.

Types#

A record is a type. A sum type is a choice. Both take generic parameters with of. 

type Doc:
    title: String
    body: String

type Pair of (A, B):
    first: A
    second: B

choice Format:
    Plain
    Markdown
    Json

choice Tree of T:
    Leaf(T)
    Node(Box of (Tree of T), Box of (Tree of T))

Construction takes named arguments in any order: Doc(title: "a", body: "…"). A trailing comma is allowed everywhere a list is.

Generic arguments

Array of Doc                       # one argument needs no parentheses
Map of (String, Int)               # two or more do
Array of (Map of (String, Int))    # nesting follows the same rule
(Array of Doc).new()               # an associated call needs its own parentheses

Map of String, Int in a parameter list cannot be parsed — that Int could be Map's second argument or the function's second parameter — so several arguments take parentheses. Array of Doc.new() is ambiguous for the same kind of reason and the compiler reports it specifically, says which reading it took, and offers the parenthesised form as a fix.

Const generics

type Grid of (T, const ROWS: Int, const COLS: Int):
    cells: Array of T

A generic parameter may be a type or a constant. Const generics are in the core because tensor shapes are built out of them: Tensor of (F32, (batch, 768)) carries 768 as an argument, and 768 is not a type.

Functions#

Generic parameters follow the name with of. Bounds go inline or in a where clause; several join with +. 

def summarize(doc: borrowed Doc) -> String:
    doc.body.truncate(200)

def duplicate of T: Clone + Eq(value: borrowed T) -> Pair of (T, T):
    Pair(first: value.clone(), second: value.clone())

def best_of of T(left: borrowed T, right: borrowed T) -> String
        where T: Summarize + Clone:
    if left.summarize().length() >= right.summarize().length():
        left.preview()
    else:
        right.preview()

def paired of (A, B)(first: A, second: B) -> (A, B):
    (first, second)

The last expression of a body is its value; return is for leaving early. A function with no return type returns ().

If you are arriving from Python, the word is the same and the declaration is not. def introduces every function form there is — a free function, a method inside a has block, a required or defaulted member of an interface — so there is no second spelling to learn for any of them. Parameters carry types, the return type follows ->, and there is no implicit receiver: self is a parameter you write, and writing it is what makes a function a method rather than an associated one.

Interfaces#

An interface may carry required methods, default bodies that call them, and associated types. 

interface Summarize:
    def summarize(self) -> String

    # A default body may call any other method of the interface.
    def preview(self) -> String:
        self.summarize().truncate(80)

Doc implements Summarize:
    def summarize(self) -> String:
        self.body.truncate(200)

Position implements Copy           # a marker: one line, no block

Receivers

def summarize(self)            # shared borrow of the receiver
def reset(mutable self)       # exclusive borrow
def into_title(self: Self)    # consumes it

Associated types

interface Iterate:
    type Item
    def next(mutable self) -> Self.Item?

Countdown implements Iterate:
    type Item is Int

    def next(mutable self) -> Self.Item?:
        if self.remaining <= 0:
            null
        else:
            self.remaining be self.remaining - 1
            self.remaining

An exhausted iterator returns null. Self.Item? is the nullable type; there is no wrapper to construct, so the present case is the value itself. changing

Methods of your own

Note has:
    def new(text: String) -> Note:
        Note(text: text)

    def is_empty(self) -> Bool:
        self.text.is_empty()

let n be Note.new("inferred, never written")

A function with no self is an associated function and is called through the type.

Operators are interfaces

Vector2 implements Add:
    def add(self, other: Vector2) -> Vector2:
        Vector2(x: self.x + other.x, y: self.y + other.y)

Add Sub Mul Div Rem Pow MatMul Neg Index Eq Ord Copy Clone Drop Iterate From Display. A scientific language in which + does not work on your own type is not a scientific language, so implementing them is how a user type joins in. Eq and Ord are what the comparisons dispatch to.

Ownership and borrows#

Memory is managed at compile time with full region inference. There are no lifetime annotations to write — the regions are inferred, including across function boundaries. 

def retitle(doc: mutable borrowed Doc, title: String):
    doc.title be title

def compare(left: borrowed Doc, right: borrowed Doc) -> Bool:
    left.title is right.title

type View:
    source: borrowed Doc           # a record may hold a borrow; the region is inferred

def main():
    let mutable doc be Doc(title: "a", body: "")

    # A parameter declared `borrowed` is borrowed automatically, so the call
    # site is bare. The signature still carries the information.
    retitle(doc, "renamed")
    compare(doc, doc)

    # Write the borrow out where the position is not a call site.
    let view be View(source: borrowed doc)

Dynamic dispatch

def describe_any(value: borrowed any Summarize) -> String:
    value.preview()

any Interface is the alternative to monomorphization and is used behind an indirection — a borrow or a box.

Control flow#

if/else is an expression. A block is an indented body after :, or a single expression written inline. 

# The inline body ends where the EXPRESSION ends, not at the newline: the
# then-branch stops at `else`, because `else` cannot continue an expression.
def preview(text: borrowed String, limit: Int) -> String?:
    if text.is_empty(): null else: text.truncate(limit)

An inline body may be an expression, an assignment, or return / break / continue. It may not be a let, which would bind a name nothing could use. A dangling else binds to the innermost if.

Two loops

for i in 0..width:                 # half-open
    print(i)

for i in 0..=n:                    # inclusive, visits `n`
    total be total + i

for row in rows:
    print(row.name)

# `loop` is the only unbounded loop; `break` ends it. There is no `while`.
loop:
    if not converged(state):
        break
    state be refine(state)

Patterns#

match is exhaustive; a missing case is an error that lists the patterns left out. An arm is inline after its :, or an indented block. 

match format:
    Plain: "plain"
    Markdown: "markdown"
    Json: "json"

match format:                      # qualified variants mean the same thing
    Format.Plain: "plain"

match digit:
    0 | 1 | 2: "small"
    3 | 4 | 5 | 6: "medium"
    _: "large"

match token:
    Symbol(',') | Symbol(';') | Symbol('.'): true
    _: false

match point:
    Point(x: 0, y: 0): "origin"
    Point(x: 0, y: y): "on the Y axis"
    Point(x: x, y: 0): "on the X axis"
    Point(x: x, y: _): "general"

Errors changing#

Designed, not yet compiled

Everything in this section is the language as decided, and it is the one area of the language sciencec does not accept yet — here and wherever else on this page a block is marked changing, which is everywhere T? or null appears. It changes what programs mean rather than how they are spelled, so it is being staged on its own. A compiler installed today rejects Error? and still accepts the removed forms shown at the bottom of this section.

A function that can fail returns its value and an error

def read_config(path: String) -> (Config, Error?):
    let text, err be read_file(path)
    if err?:
        return (Config.empty(), err)

    return (parse(text), null)

The error type is nullable and ? asks whether it is there. T? is T or null, which is the spelling Kotlin, Swift, TypeScript and C# already use. Inside if err?: the compiler knows err is not null, and after an early return guarded by it the value is known good; that narrowing is what keeps the model from being cast-ridden.

Error is a one-method interface — def message(self) -> String — so Error? in a return position is shorthand for (any Error)?. A function may name a concrete choice instead, and should when the caller is expected to tell the cases apart, because that is what keeps match exhaustive. Conversion between the two is written out at the return: there is no implicit widening.

What it replaces — removed, shown only for comparison

Not valid Science · removed in syntax revision 2

function read_config(path: borrowed String) -> Result of (Config, Error):
    let text be try read_file(path)
    let config be try parse(text)
    Ok(config)

Do not write this. It is kept because the shape of the change is easier to see against what it replaces, and because sciencec is the one thing that still accepts it. In the removed model try unwrapped an Ok or a Some and returned the failure otherwise; it was a prefix and bound the whole chain to its right, so (try f()).port needed its parentheses. Result of (T, E), Option of T, try, Ok, Err, Some and None all go together, and the implicit From widening that try performed goes with them.

Chains and closures#

The shape most Science code takes is a chain of method calls. A line whose continuation begins with . continues the line above it. 

def headlines(docs: borrowed Array of Doc) -> Array of String:
    docs
        .iterate()
        .discard(each.is_empty())
        .map(each.title)
        .take(5)
        .collect()

def by_length(docs: borrowed Array of Doc) -> Array of String:
    docs
        .iterate()
        .map(doc giving doc.summarize())
        .sort(by: line giving line.length())
        .collect()

Two closure forms. each names the subject of the enclosing call without declaring it. name giving expression declares the parameter, and is required when the parameter is used more than once and for the one case each cannot express: nesting, where two each would refer to different things. A nested each is rejected rather than guessed at, and the error names the giving form.

Calls always take parentheses, including when they take no arguments: text.length(), never text.length. Once functions are values, doc.summary is ambiguous between calling it and naming it, and a language cannot resolve that by guessing. Parentheses mean call; their absence means a field.

Foreign code#

Essentially every floating-point operation that matters in scientific computing already lives in a C or Fortran library somebody else tuned. An extern block declares what Science may call; the block is unsafe because the declaration is a claim the compiler cannot check. 

unsafe extern "C" library "openblas" via pkg-config "openblas":

    type CblasLayout is CInt
    type CblasTranspose is CInt

    const CBLAS_ROW_MAJOR be 101 as CblasLayout
    const CBLAS_COL_MAJOR be 102 as CblasLayout

    def cblas_dgemm(
        layout: CblasLayout,
        transpose_a: CblasTranspose,
        m: BlasInt,
        n: BlasInt,
        a: ffi.Span of F64,
    ) symbol "cblas_dgemm"

    static H5T_NATIVE_DOUBLE_g: Hid
    union H5R_ref_t: size 64 align 8

Five item forms: def, type alias, const, static for a global whose value the loader sets, and union as an opaque blob of a known size and alignment. symbol decouples the Science name from the linker name.

Linking

unsafe extern "C" library "openblas64_" kind static:
unsafe extern "C" library "cudnn" when available:

via pkg-config takes the flags from the system, which is the only thing that gets BLAS right across machines. kind static forces static linking; dynamic is the default, because cluster module systems work by swapping the shared object under a fixed name. when available makes a library optional and loaded on first use, so a program that can use a GPU still starts on a node without one.

The interface is the wrapper, not the declaration

def multiply(a: borrowed Matrix, b: borrowed Matrix) -> (Matrix, BlasError?):
    if a.columns is not b.rows:
        return (Matrix.empty(), BlasError.Shape(a.columns, b.rows))

    unsafe:
        cblas_dgemm(
            layout: CBLAS_COL_MAJOR,
            transpose_a: CBLAS_NO_TRANS,
            m: a.rows as BlasInt,
        )
    (result, null)

Named arguments are permitted at a foreign call site — thirteen-argument dgemm has two transposition flags that look identical, and confusing them produces a wrong answer rather than an error. The safe wrapper is where the unverifiable half of the claim is discharged by a check a human wrote.

The wrapper names a concrete BlasError rather than the Error interface, because a caller that gets a shape mismatch back wants to match on which mismatch it was, and because the interface form boxes where the concrete form does not. changing

Toolchain#

CommandDoes
sciencec check FILE…Lex, parse and resolve. Reports every file, continuing past a broken one.
sciencec tokens FILEThe token stream, with spans.
sciencec ast FILEThe syntax tree.
sciencec resolve FILEThe definition table after name resolution.

Dumps go to stdout, diagnostics and the summary to stderr. Exit 0 when there are no errors, 1 when there are; warnings alone do not fail. Every diagnostic carries a code, a primary span, and where a mechanical fix exists, the replacement text — a tool can apply it without reading the prose.

Comparisons

One spelling per operation. Identity is a word because no symbol for it is universal — == is a programming convention, and the languages that have it disagree about what it means for objects. Ordering is a symbol because >= is four hundred years old and every reader of a paper already reads it.

Assignment is absent because it is a statement, not an operator. Ranges sit below everything, so 0..n - 1 counts to n-1.

try used to share rung 01. It was removed with the Result model and nothing has taken its place: the presence test ? that replaces it is a different shape, so the rung is vacant rather than reassigned.

Open — where ? binds

Syntax revision 2 §3.1 settles that the presence test is postfix and that err? is a Bool. It does not say what it binds tighter or looser than, and every example it gives applies ? to a bare name, so this table deliberately has no rung for it. Two questions are open and the note answers neither:

1. Does ? take a whole postfix chain, so that config.port? and next()? parse, or does it test only a binding? 2. If it joins rung 01, it sits beside the T? of a nullable type, which is a different production with the same character — and the note does not say how a reader or a parser tells Foo? the type from Foo? the test where both could stand.

Guessing a rung here would teach something false, so the gap is left visible. It closes when the spec revision §9 asks for lands.

Blocks and line continuation

Blocks are delimited by indentation, spaces only — a tab in the indentation is an error with no attempt to interpret it, because its width depends on how the file is displayed and a block would then mean different things to different readers. Blank and comment-only lines take no part. Comments run from # to end of line; there are no block comments. 

# A line continues when it ends inside an unclosed bracket...
use compiler.frontend.diagnostics (
    Diagnostic,
    Label,
)

# ...when the next line begins with `.`, which is how a chain is broken...
let names be docs
    .iterate()
    .collect()

# ...and when it begins with `where`, before a signature's bounds.
def largest of T(items: borrowed Array of T) -> borrowed T
        where T: Ord:
    items.get(0)

Those two words are the whole list, and it is meant to stay that way: a line break is otherwise the end of a statement, and a reader should not have to look ahead to know whether it was.

Reserved words

    Held for later phases — using one is an error

      Deliberately not reserved

        Each of the last group is a common variable name in the code of the audience Science is for, and that outranks the convenience of reserving it.

        The first list is the lexer's, word for word. try left it and null joined it with revision 2, and revision 3 replaced function with def; sciencec has caught up with all three, so none of the three is a divergence any more. A word the language removed is still recognised where it used to stand, and reported as a migration rather than treated as a stray name: SC0156 for function, which carries def as a fix an editor can apply, and SC0155 for try, which carries none on purpose — the model that replaced it turns one expression into a binding, a test and a return, and no mechanical rewrite can choose what to return.

        Twenty-one worked programs live in examples/; they are input data for the compiler's own test suites, so anything there that fails to lex, parse or resolve is a bug in the compiler rather than a typo to be quietly patched. Programs that must fail, each paired with the exact diagnostic it has to produce, live in tests/ui/.
